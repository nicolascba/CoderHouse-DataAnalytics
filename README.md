## 🛒 Proyecto integrador: RetailPro

RetailPro es un proyecto de análisis de datos orientado al ámbito comercial y retail, cuyo propósito es transformar datos de ventas en información útil para la toma de decisiones.

El proyecto contempla distintas etapas del proceso analítico:

1. **Preparación de datos:** limpieza, transformación y validación de las fuentes.
2. **Modelado de datos:** organización de tablas de hechos y dimensiones, junto con sus relaciones.
3. **Análisis con SQL:** consultas para explorar información y obtener hallazgos relevantes.
4. **Desarrollo en Power BI:** construcción de indicadores y visualizaciones para analizar el desempeño comercial.
5. **Dashboard ejecutivo:** diseño de una vista general de ventas que facilite la interpretación de los resultados.

Entre los aspectos de análisis considerados se encuentran la evolución temporal de las ventas, el desempeño por categorías y productos, las diferencias entre canales de venta y los indicadores clave del negocio.
