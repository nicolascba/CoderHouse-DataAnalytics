## 🛠️ Herramientas y tecnologías

- **Excel:** organización y exploración de datos.
- **Power Query:** preparación, limpieza y transformación de los datos mediante procesos ETL.
- **SQL Server:** creación y consulta de tablas relacionales mediante `SELECT`, `JOIN`, `GROUP BY` y `HAVING`.
- **Power BI:** modelado de datos, creación de medidas y desarrollo de dashboards.
- **DAX:** creación de cálculos, indicadores y análisis temporal.

## 🛒 Proyecto integrador: RetailPro

RetailPro es un proyecto de análisis de datos orientado al sector comercial y retail. Su objetivo es transformar datos de ventas en información útil para facilitar la toma de decisiones y evaluar el desempeño del negocio.

El proyecto contempla las siguientes etapas:

1. **Preparación de datos:** limpieza, transformación y validación de las fuentes mediante Power Query.
2. **Modelado de datos:** organización de tablas de hechos y dimensiones, creación de relaciones y estructuración de un modelo analítico.
3. **Análisis con SQL:** consultas para explorar la información, identificar patrones y obtener hallazgos relevantes.
4. **Desarrollo en Power BI:** creación de medidas e indicadores mediante DAX para analizar el desempeño comercial.
5. **Dashboard ejecutivo:** diseño de visualizaciones que permitan interpretar los resultados de forma clara y facilitar el seguimiento de los principales indicadores del negocio.

### Indicadores y análisis

El dashboard de RetailPro está orientado al análisis de:

- Ventas totales por período.
- Evolución mensual de las ventas.
- Desempeño de ventas por región y territorio.
- Ventas por categoría y producto.
- Comparación del ticket promedio entre los canales online y presencial.
- Indicadores clave de desempeño (KPI).
- Detalle de las transacciones para facilitar el análisis.

## ▶️ Cómo ejecutar los scripts SQL

Los scripts SQL del proyecto pueden ejecutarse utilizando **SQL Server Management Studio (SSMS)**.

### Requisitos previos

- Tener SQL Server instalado y en funcionamiento.
- Contar con SQL Server Management Studio (SSMS).
- Descargar o clonar el repositorio de GitHub.

### Pasos para ejecutar los scripts

1. Clonar o descargar el repositorio desde GitHub.
2. Abrir SQL Server Management Studio y conectarse a la instancia de SQL Server.
3. Abrir el archivo `.sql` que se desea ejecutar desde el repositorio.
4. Ejecutar primero el script de creación de la base de datos y las tablas, si corresponde.
5. Ejecutar los scripts de carga de datos antes de las consultas que dependan de ellos.
6. Seleccionar la base de datos correspondiente y ejecutar las consultas mediante el botón **Execute** o la tecla `F5`.
7. Revisar los resultados obtenidos en la pestaña de resultados de SSMS.

**Importante:** los scripts deben ejecutarse respetando el orden de sus dependencias. Los nombres de las tablas y de la base de datos deben coincidir con los definidos en cada archivo.
